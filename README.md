# OpenAI Studio - Android App 🚀

تطبيق أندرويد متكامل ومصمم بـ **Jetpack Compose** و **Kotlin** لتشغيل استراتيجيات الذكاء الاصطناعي والتداول واستخدام نماذج OpenAI.

---

## 📥 تحميل ملف الـ APK المباشر (Direct Download):
1. افتح تبويب **[Actions](../../actions)** في هذا المستودع.
2. اضغط على أحدث عملية بناء (Build Android APK).
3. في أسفل الصفحة عند قسم **Artifacts**، اضغط على **OpenAI-Studio-Debug-APK** لتحميل التطبيق مباشرة على هاتفك وتثبيته!

---

## 🛠️ الفتح والتطوير عبر Android Studio:
1. افتح **Android Studio**.
2. اختر **Open** وحدد هذا المجلد.
3. اضغط **Run** لتشغيل التطبيق على المحاكي أو جهازك الحقيقي.
